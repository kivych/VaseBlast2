# Vase Blast 2

Уютная браузерная головоломка «три в ряд» с цветами. Одностраничная HTML5-игра
без внешних зависимостей: вся графика, звук и логика лежат в одном `index.html`.

**Играть:** https://kivych.github.io/VaseBlast2/

## Как играть

Переставляйте цветы между восемью горшками. Три одинаковых в одном горшке — и он
взрывается, принося очки. Взрывы подряд складываются в комбо до x5.

Два режима: «На время» (результат идёт в таблицу рекордов) и «Спокойно»
(без таймера и без проигрыша). Переключаются из паузы.

## Что внутри

- 14 видов цветов, открываются по мере роста уровня
- коллекция цветов, которая копится между партиями
- кот-компаньон: спит, реагирует на прикосновение, ловит рыбку за комбо x5
- три языка интерфейса: русский, английский, китайский
- прогресс сохраняется локально и в облако Яндекс.Игр

## Технически

Один файл, 2,7 МБ. Графика — WebP в base64, фоновая музыка — вшитый AAC-луп,
звуковые эффекты синтезируются через WebAudio API. Внешних сетевых запросов нет,
кроме Yandex Games SDK при запуске внутри платформы.
