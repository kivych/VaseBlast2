Политика конфиденциальности

Игра Vase Blast 2. Обновлено: 23 сентября 2026 г.

Коротко

Игра не собирает, не хранит и не передаёт персональные данные. Нет регистрации, нет форм ввода, нет аналитики, нет рекламных идентификаторов.

Какие данные обрабатываются

Игра сохраняет только игровой прогресс: счёт, номер уровня, расстановку цветов, выбранный режим, собранную коллекцию и лучшее время прохождения. Эти данные не позволяют идентифицировать человека.

В версии для Android прогресс хранится исключительно на устройстве (localStorage внутри приложения) и никуда не отправляется. При удалении приложения он удаляется вместе с ним.

В браузерной версии на платформе Яндекс.Игры прогресс дополнительно сохраняется в облако средствами Yandex Games SDK, чтобы игру можно было продолжить на другом устройстве. Обработка таких данных регулируется политикой Яндекса.

Дети

Игра рассчитана на любой возраст и не содержит контента, не подходящего детям. Персональные данные детей не собираются.

Разрешения

Android-версия не запрашивает разрешений: ни камеры, ни микрофона, ни геолокации, ни контактов, ни хранилища, ни списка установленных приложений.

Третьи лица

Android-версия не содержит рекламных сетей и сторонних SDK. Браузерная версия на Яндекс.Играх показывает рекламу средствами платформы.

Изменения

Если политика изменится, новая редакция будет опубликована на этой странице с новой датой обновления.

Privacy Policy

Vase Blast 2. Last updated: 23 September 2026.

Summary

This game does not collect, store or transmit personal data. There is no sign-up, no input forms, no analytics and no advertising identifiers.

What is processed

The game saves game progress only: score, level, the layout of flowers, the chosen mode, the collected flowers and the best completion time. This data cannot identify a person.

In the Android version progress is stored solely on the device (localStorage inside the app) and is never uploaded. Removing the app removes it.

In the browser version on the Yandex Games platform, progress is additionally saved to the cloud through the Yandex Games SDK so the game can be continued on another device. Such processing is governed by Yandex's own policy.

Children

The game is suitable for all ages and contains no content unsuitable for children. No personal data of children is collected.

Permissions

The Android version requests no permissions: no camera, microphone, location, contacts, storage or installed-apps list.

Third parties

The Android version contains no ad networks and no third-party SDKs. The browser version on Yandex Games shows ads provided by that platform.

Changes

If this policy changes, the new version will be published on this page with a new update date.
